# 第一人称枪战小游戏

一个零依赖的浏览器 WebGL 小游戏。

## 操作

- 点击画面锁定鼠标，`Esc` 释放鼠标
- `WASD` 移动，`A` / `D` 侧移
- `Shift` 跑步
- `空格` 跳跃
- `F` 拾取附近枪械（会替换手里的枪）
- `E` 丢弃当前武器
- `1` / `2` / `Q` 切换武器，带收枪抬枪动画
- 持枪时左键射击，右键开镜
- 空手时左键挥拳

## 已有内容

- 棕色地面、掩体墙和障碍物都是实体，不能穿墙
- 枪和手也是实体：正对墙或侧着走贴墙时，模型和枪会收回，不会穿进墙里
- 地图中会生成 AUG、AKM、M4A1，最多带 2 把
- 三把枪射速、后坐力、枪声都不同
- 走路、跑步是不规则的踩草地声；挥拳时不播脚步声
- 子弹打中墙面会留弹痕，一段时间后消失
- 开镜时隐藏枪支，只保留准星和瞄具遮罩

## 运行

在项目目录启动静态服务器：

```bash
python3 -m http.server 4174
```

然后打开：

```text
http://localhost:4174/?v=36
```
